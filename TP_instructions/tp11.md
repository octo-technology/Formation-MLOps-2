## Mettre en place une brique de shadow production

Duration: 0:10:00

Modifier le dag d'inférence en ajoutant une étape de shadow production

```python
@task
def shadow_production_with_io_task(feature_path: str) -> None:
    shadow_predict_with_io(features_path=feature_path,
                           model_path=...,
                           db_con_str=...,
                           shadow_monitoring_table_name=...)
```

Et créer la fonction `shadow_predict_with_io` qui fait la prédiction avec le shadow model et enregistre la métrique de monitoring dans PostgreSQL, pour l'afficher dans Grafana. 

```python
def shadow_predict_with_io(features_path: str,
                           model_path: str,
                           db_con_str: str,
                           shadow_monitoring_table_name: str) -> None:
    # Read features
    features = ...
    # Load model
    model = ...
    # Predict with shadow model
    features["predictions"] = model.predict(features)
    time_str = time.strftime('%Y%m%d-%H%M%S')
    features['predictions_time'] = pd.to_datetime(time_str, format='%Y%m%d-%H%M%S')
    # Compute metrics
    monitoring_df = monitor(features[['predictions_time', 'predictions']])
    # Send metrics to postgresql
    engine = create_engine(db_con_str)
    with engine.begin() as db_conn:
        monitoring_df.to_sql(shadow_monitoring_table_name, con=db_conn, if_exists='append', index=False)
    engine.dispose()
```
